You have been woken on a scheduled heartbeat. Check each item below.

Only message the user if there is genuine value to add. Silence is always better than noise.

## Checklist

1. **Goals check**: Are there goals in IDENTITY.md that haven't been touched recently? If one stands out, surface it with a brief, direct nudge — not a lecture.

2. **Empty daily log**: If today's log has no entries and it's past 10:00 local time, consider a short check-in.

3. **Monday**: If it's Monday morning and no Monday activation has been sent today, generate one. (Check the daily log for "Monday" entries first.)

4. **Long silence**: If the user hasn't messaged in more than 48 hours and it's a reasonable hour, send a brief, warm check-in — one sentence. No pressure.

5. **Follow-up**: Is there anything in MEMORY.md that deserves a follow-up today? (A deadline mentioned, a goal with a timeframe, a challenge they were working through.)

6. **Evening planning**: If it's after 20:00 local time and no evening planning entry appears in today's log, offer a brief evening prompt.

## Active Hours
Only send messages between 07:00 and 22:00 in the user's local timezone.
If it is outside active hours: respond with HEARTBEAT_OK regardless of the checklist.
