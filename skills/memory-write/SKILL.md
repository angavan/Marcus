# Memory Write

Use the `write_memory` tool to persist information across sessions.

## Daily Log (permanent=false)
Write here after every meaningful exchange. These are working notes — they persist for the day and are loaded at the top of each session.

Write after:
- Any significant conversation
- A task completed or discussed
- A check-in or proactive message sent
- Something the user told you that doesn't rise to permanent importance yet

## MEMORY.md (permanent=true)
Write here for facts worth keeping indefinitely. This file is loaded every session and grows over time.

Write permanently when you learn:
- A new or changed goal
- An important life decision the user made
- A pattern you've noticed (e.g. "tends to avoid marketing tasks")
- Key context that defines who they are (job change, relationship, major project)
- Something they explicitly want you to remember

## Format
Be concise. Write as notes, not essays. Include the date context when relevant.

Bad: "The user today told me that they are working on building a fitness application and they mentioned that they have been struggling with the marketing side of things and specifically with user acquisition."

Good: "Building a fitness app. Main challenge: user acquisition / marketing. Tends to avoid this topic."
